## 方向与取舍

第二轮曾比较字母 S 与几何台阶。用户选择后者，因为它直接连接 Step“一步一步推进”的含义。本轮保留单级台阶、水平端口和小转角，不添加箭头、多级阶梯、脚印或装饰圆点。

本轮的具体几何、配色和排版是设计提案，仍须用户确认。

- 主轮廓：108 × 108 网格，视觉中心位于 (54, 54)，可见范围为 60 × 48.5。笔画从原稿 12 调整为 10.5，两个横段保持旋转对称；小内圆角与外角分别做光学修整，不改成粗圆角折线。
- 颜色：深松绿 `#214638`，暖白 `#F5F2E9`。图标不加金色端点、光泽或纹理；产品内有语义的重点色不因此改变。
- 字标：小写 `step`，Medium 字重；当前展示为排版提案，不另加一个产品界面的功能或入口。
- 小尺寸：16 px 模板另做像素对齐；18 px 画布居中放置同一模板。24 / 32 px 单色示意用于观察轮廓。最终接入后仍需在系统实际渲染中验收。
