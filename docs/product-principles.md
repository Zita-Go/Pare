# Pare 产品原则

用户确认于2026-10-30：成熟应用的研究可以改善基础体验，但 Pare 必须突出自己的功能与设计，不能按竞品的功能清单发展。

## 核心价值

Pare 帮助人把脑中的模糊想法变成能够开始、持续推进和回看的行动，尤其照顾缺少动力、容易分心、任务跨度长，以及需要等待其他人或AI执行结果的使用场景。

核心路径是：**接住想法 → 分清轻重 → 选出今天 → 找到最小下一步 → 推进与回看**。

## 需要保留和突出的特点

1. **想法可以慢慢长成项目。** 早期想法不是必须立刻完成的待办；保留背景、探索、发现和决定，再连接具体行动。
2. **四象限承担取舍。** 分类最终服务于今天的有限精力和容量，不能只变成四个装饰性分组。
3. **帮助开始。** 今日重点、最小下一步、完成标准、短时启动和卡点支持应降低行动门槛，避免不断要求用户做更多设置或选择。
4. **个人投入与并行推进分开。** 用户可能在多台机器上使用不同AI；Pare跟踪用户选择记录的进行状态、等待和检查节点，不假设能够看见或管理那些AI。
5. **AI建议有前情。** 在用户授权的范围内参考任务、想法、长期目标、偏好和历史反馈；说明建议依据，让用户决定采纳。AI原始历史与服务密钥按既定隐私边界留在本机。
6. **提醒温和、状态可信。** 自动保存、同步、恢复和错误反馈准确；轻度主动提示需要有理由，调用AI保持明确、可控。

## 如何借鉴成熟应用

可以借鉴：可扫描的列表、按需展开、可触达的控件、清楚的导航、稳定的状态反馈、键盘与大字体适配，以及经验证的设计系统方法。

功能与页面的去留，按以下问题决定：它如何帮助上述核心路径？是否减少启动阻力或理清取舍？能否保留想法和行动之间的联系？是否给用户增加了不必要的管理工作？竞品是否拥有某功能不构成加入理由。

保留Pare的识别性，同时让颜色承担明确含义：重点、进行状态、取舍和反馈。不要用全屏品牌色、装饰性卡片或大量文案代替产品价值。

## 品牌与图标审批

2026-11-02用户选择Step作为新的品牌方向，表达一步一步完成任务、达到目标和提升自我。用户同时明确：当前图标提案偏toy、不够专业，**具体图标必须经用户明确同意后才能实施**。先提供候选图和实际小尺寸效果；未批准稿只能作为设计评审素材，不能替换应用资源、默认构建图标或正式安装。对名称方向的同意不等于批准任何具体图标。

同日用户提供成熟桌面图标参考，进一步明确可以使用圆点、光泽与渐变，并以阶梯、类似贪吃蛇的连续路线表达达成目标。不能把“专业”机械等同于纯扁平或禁止材质；光影和装饰需服务于清楚的形体与目标语义。最终图标仍须明确批准。

随后用户认为深色材质版过于复杂，最新方向为：更简洁、以白色为底层，再添加适度质感。保留此最新偏好，不再默认使用深色玻璃底。具体白底方案仍待用户确认。

用户进一步明确保留原来的S形与圆球，不改成实体三级阶梯；用所提供参考图中的简单色块、折面和遮挡表达空间感，避免厚浮雕和大投影。最新候选仍需明确批准后才能实施。

用户强调阶梯与贪吃蛇两种含义要同时突出，并要求比较端口斜切、方角或更平滑转角等版本。S形路径和前方圆球不能退化为无关联的装饰，具体端口与转角仍待选定。

**已批准：**2026-11-02用户明确选择第八轮 C（“用C吧”）：切角＋斜切端口，白底、绿色折面 S 与金色圆球。可据此制作并接入正式资源；以[已批准设计](brand/step/approved-c.md)为准，无需再次询问是否使用 C。

2026-11-06用户查看第九轮比例与材质细化的大图和桌面小尺寸后回复“合适”，批准将其接入正式资源并本地替换：主体更高、略厚，保留白底、C轮廓与金球，增加柔和质感。当前彩色依据更新为[第九轮确认稿](brand/step/review-09/step-fuller-material-1024.png)，无需重复确认。
