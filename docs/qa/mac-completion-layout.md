# Mac 四象限完成操作复测

使用独立的虚构资料库与真实生产视图：

```sh
bash Scripts/screenshot-demo.sh --compact --readme-matrix --completion-regression
```

该用例为 880×620 窗口，四象限分别有 3、1、7、1 项任务。左下象限含长短标题、已完成项和今日标记；点击「完成回归项」的圆圈，会同时发生完成排序、行高变化及实际用时提示展开。没有估时和实际用时，所有提醒关闭，不连接真实账号。普通截图启动参数的资料不变。

检查步骤：

1. 点击「完成回归项」圆圈，确认完成状态及今日进度更新。
2. 滚至左下象限底部，确认用时提示可见且没有持续布局阻塞。
3. 点击「跳过记录实际用时」，确认提示能关闭，列表仍可滚动和编辑。
4. 对照使用键盘空格完成（不自动展开提示），以及已完成项的「记用时」（不改变排序），区分排序和展开的影响。
5. 若出现持续高 CPU 或无响应，先对独立演示进程采样，再改一项布局约束比较；不能只看一次 CPU 峰值判断卡死。

当前验证：独立演示构建成功，圆圈完成、滚至底部和跳过提示能够响应；尚未用此用例稳定复现间歇性布局循环。因此这里记录的是诊断用例，不是根因修复的证明。
