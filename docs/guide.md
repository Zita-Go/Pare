# Pare 使用指南

[返回首页](../README.md)

## 随手记与整理

点击菜单栏图标或按 `⌥Space` 唤出输入框，写一句话并回车保存；点别处收起。点击「今日任务」可收起或展开清单，点击底部「整理」进入大窗口。

「待整理」里的内容可以拖进四象限，或选中后按 `1`–`4` 归位。没有待整理内容时，左侧自动收成窄栏。象限内也能直接添加任务。

想法不一定要变成待办。待整理卡片上的灯泡可以把内容保留为想法；在「想法与历史」里继续写备注、安排下次回看，想清楚后再转成任务。

## 今日计划与五分钟启动

在四象限点任务旁的太阳加入今天，再到「今日计划」调整顺序。星标代表「今日关键任务」，同时只选一件。容量提示按预估时长计算，未估时任务会单独注明。

点「开始 5 分钟」开始正向计时。五分钟是一次检查点，到点通知提供「继续 / 暂停 / 完成」；计时不会自动把任务标为完成。通知能否展示受系统通知权限和专注模式设置影响。

也可以使用任务上的专注按钮开始普通计时。停止时累计本段实际用时，并询问是否完成；选择「还没」仍保留投入。计时旁的 `×` 或右键的放弃操作不记录本段用时。电脑休眠会停止并记录计时，正常退出后重开则恢复正在运行的计时。

## 我卡住了

从今日计划顶部点「我卡住了」，或点「拆小一步」直接从“任务太大”开始。

| 当前卡点 | 可以怎么开始 |
| --- | --- |
| 不知道下一步 | 写出一个具体动作，例如打开文件、列出一个问题 |
| 任务太大 | 只找出一个 5–15 分钟的小步骤 |
| 没有精力 | 缩小动作，或选择今日清单里较短的一件 |
| 有压力或抗拒 | 写下最低完成版本，允许先做得不完美 |

示例：把「完成报告」的下一步写成「打开文档，先写三个小标题」，最低完成版本写成「列出结构和要点，暂时不用润色」。可以只保存，也可以保存并开始五分钟。默认提供本地填写引导；需要按任务生成建议时，可主动点击「帮我想一个起点」。

今日小结记录完成数、启动次数、推进任务数和已停止计时的投入；当天记录过的卡点也会参与汇总。本周回顾和最近八周趋势可帮助回看完成节奏、四象限分布以及预估与实际用时的差异。

## 任务详情、日期与提醒

点任务的「…」编辑标题、下一步、完成标准、思考备注、象限和预估，也可以设置加入今天、今日关键任务、截止日期和提醒。

- 截止日期与提醒互相独立。只设截止日期不会自动发送提醒。
- 提醒可选具体日期时间，也支持每天、每周、每月重复；当前重复规则作用于提醒，不会自动复制一份新任务。
- 「想法与历史」的「截止」页按已逾期、今天、未来七天和更晚分组。
- 随手记支持简单语句，例如 `30分钟后提醒我喝水`、`明天下午3点提醒我写报告`；归位成任务后会带上解析到的提醒时间。

任务提醒的通知可以直接完成或延后。晨间规划默认 9:00，晚间收尾默认 18:00，本周回顾默认周日 20:00；在「提醒设置…」里调整或关闭。

### 如果—那么启动计划

在任务详情中打开「如果—那么启动计划」，选择触发条件，并填写一个明确动作：

- **到指定时间：** 例如每天 9:30 提示「打开文档，写三个小标题」。任务完成或关闭计划后停止安排。
- **回到电脑时：** 通过屏幕唤醒、会话恢复事件触发；不是持续追踪用户是否坐在电脑前。
- **打开应用时：** 选择一个当前运行的应用，之后切换到该应用前台时触发。

后两种触发需要 Pare 正在运行，同一任务有四小时冷却；同时符合条件时优先选今日关键任务和今日任务。可在详情里关闭计划。为接收提醒，请先授权系统通知。

## AI 辅助

AI 默认关闭。右键菜单栏 →「提醒设置…」→「AI 辅助（可选）」配置：

1. 填写 OpenAI 兼容的 API 基础地址和服务中实际可用的模型 ID。例如本机 Ollama 地址为 `http://127.0.0.1:11434/v1`；云端必须使用 HTTPS。
2. 填写 API Key，本机 Ollama 通常可留空。密钥按接口地址保存在 macOS 钥匙串中；更换接口地址不会复用旧服务的密钥。
3. 开启并保存设置，点「用示例测试连接」。这会发送一个虚构任务，占用一次请求额度，不会发送真实任务。
4. 从待整理、今日计划或「我卡住了」进入 AI 面板。选择发送内容、预览后点击发送，检查结果后再采纳。

支持 `/v1/chat/completions` 兼容协议，不是任意厂商的原生接口。使用其它协议的服务需配置兼容网关。「请求严格 JSON Schema」要求服务支持对应参数；遇到不兼容错误可关闭并手动重试。无论是否开启，Pare 都会校验 JSON、任务来源、时间预算和字段长度，拒绝不完整结果。

### 发送与采纳范围

- 一次最多选 20 条、输入不超过 32 KB；候选清单展示前 60 条。下一步请求只针对一个任务，任务备注需主动勾选。
- 可预览的内容包含选中任务或随手记、已有下一步/标准、日期、预算、精力和补充说明。通用规划指令也会发送；密钥仅用作鉴权，不进入提示词。
- AI 可以先问一个必要问题。补充回答后再次点击发送；每次调用均计入请求次数。
- 整理只归位被勾选的随手记，原文保存在备注，不自动加入今天。
- 今日计划只更新选中任务的下一步、完成标准和今日标记。其它今日任务保留，原来的整任务估时不覆盖；模型显示的是这次推进的时间预算。
- 下一步建议先填回卡点面板，由你继续编辑和保存，不会自动开始计时。
- 编辑、删除或完成了源任务后，旧建议不能再覆盖它，请重新打开 AI 面板。

### 隐私、等待和费用

启用云端服务后，发送的内容会离开本机并由该服务商处理；`store=false` 不代表服务商不留日志。请按自己的需求选择服务和发送范围。应用不会上传浏览器标题、浏览历史、未选中的任务或完整任务备份。

本机服务需要预先安装、下载并启动模型；Pare 本身不下载或运行模型。普通记事、整理和计时不依赖 AI，也不因网络失败而失效。

每次只运行一个请求，无自动重试；可取消，网络请求设有超时。每日默认最多 20 次尝试，失败或取消也计数；可以调整输出 token 上限和次数上限。这些限制只约束 Pare 请求，不是服务商的严格金额预算。密钥、模型和服务地址不随任务 JSON 导入导出。

## 注意力漂移与隐私

此功能默认关闭。在设置里开启「检测应用来回切换」后，Pare 会在内存中分析短时间的前台应用切换；开启「浏览器页面增强检测」还需要 macOS 辅助功能权限。

浏览器增强只读取当前浏览器窗口标题，立即转成进程内的临时散列来比较页面是否改变，不保存原始标题、网址或浏览历史。当前识别 Safari、Chrome、Edge、Arc、Brave、Firefox、Vivaldi 和 Opera；实际效果取决于浏览器是否提供相应的窗口标题变化事件。

正在专注计时时不触发漂移提示。分析窗口、切换阈值、冷却时间和每日次数可以调整；通知提供「开始 5 分钟 / 记录卡点 / 忽略 1 小时」。

频繁切换可能是在查资料或协作，检测无法判断工作的真实价值，也不是“有没有动力”的诊断。提示可以忽略，基础检测和浏览器增强也可以分别关闭。

## 数据、备份与每天翻篇

数据保存在：

```text
~/Library/Application Support/Pare/store.json
```

保存采用原子写入，并把上一份可正常读取的数据保留为 `store.json.bak`。主文件损坏时会尝试读取备份；两份都不可读时会停止覆盖并提示问题。

设置支持导出 JSON、导入 JSON 和恢复自动备份。导入会替换当前内容，建议先导出一份留存。Pare 当前不提供账号、云同步或跨设备同步。

每天首次使用会把已完成任务归档，清空昨日的今日选择和今日关键标记。未完成任务保留在原象限，可以重新加入今天；想恢复已完成任务，可在历史中找回。删除与清空提供十秒撤销入口。

## 常用操作

### 修改随手记快捷键

右键菜单栏图标 →「提醒设置…」→ 顶部「快捷键」。点击当前组合，按下想用的新组合，保存后立即生效，无需重启。组合至少包含 `⌘`、`⌥` 或 `⌃` 中的一个，例如 `⌃⇧Space`。

按 `Esc`、点别处或关掉设置会取消录入并恢复原组合。「恢复默认」可改回 `⌥Space`。系统保留或注册失败的组合会显示提示，并尝试保留原快捷键；如果旧组合也不能恢复，会明确显示未能注册，仍可点击菜单栏图标。

快捷键仅保存在这台 Mac 的应用偏好中，重启后恢复，不随任务 JSON 备份导入或导出。下表中的 `⌥Space` 是默认组合，修改后请使用你设置的新组合。

### 快捷操作表

| 操作 | 作用 |
| --- | --- |
| 点击菜单栏图标 / `⌥Space` | 打开或收起随手记 |
| 输入框内按回车 | 记下当前内容 |
| 点随手记以外的位置 | 收起浮窗 |
| 整理窗内按 `↑` / `↓` | 选择项目 |
| 选中后按 `1`–`4` | 归入象限 |
| 选中任务后按空格 | 切换完成状态 |
| `Esc` | 取消当前选择或关闭相应浮窗 |
| 右键菜单栏图标 | 打开整理、回顾、设置或退出 |

整理快捷键在文本编辑时会让位给输入，不会把正在输入的数字当成归位指令。

## 常见问题

**打开后怎么没有主窗口？** Pare 常驻菜单栏。点击屏幕顶部图标，或按 `⌥Space`，再点「整理」。

**为什么昨天的任务不在今日清单？** 每天重新选择重点；未完成任务仍在四象限，已完成任务在历史中。

**收不到提醒怎么办？** 右键菜单栏 →「提醒设置…」查看通知权限，点「发送测试提醒」。如果被系统关闭，在 macOS「系统设置 → 通知 → Pare」中允许通知，同时检查专注模式。系统决定通知何时展示，Pare 不保证退出专注模式后立即补弹。

**为什么有些事还没完成，小结却记了进展？** 停止的专注时段也代表投入，记录并不要求先把整个任务完成。

**普通记事是否需要辅助功能权限？** 不需要。只有可选的浏览器页面增强检测需要该权限。
