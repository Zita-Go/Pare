# Pare 可信与顺手版本

用户已认可 2026-10-29 实测评估及前两轮实施。保留原生 SwiftUI/AppKit、macOS 13、深绿暖金、本地 schema v4；不调用真实 AI，不修改用户任务用于验收，不发布远端。

## 设计与分工

- [x] 数据可信：区分未来版本与损坏；保存失败可见；导入事务失败回滚；明确自然语言提醒创建结果并立即调度。
- [x] 生命周期：使用持有到进程退出的文件锁阻止共享同一数据文件的双实例；正常退出停止个人专注；重启恢复中断专注时不把停机时间静默算入。
- [x] 今日与时间轴：当前专注优先，重点状态与计时一致；并行摘要默认折叠；顶部压缩；时间轴可缩放并回到现在。
- [x] 搜索与空间：统一全分类搜索、准确空态、Cmd-F；待整理可手动收起，今日默认收起；稳定任务行，避免悬停改变高度。
- [x] 验证与交付：核心故障回归测试、完整测试与 release 构建、多 agent 审查、隔离 UI 操作；保存旧安装后更新本机。

## 验收重点

未来 schema 不写坏原文件；写失败不能显示导入成功；第二实例不能取得锁；记录明确提醒后能生成通知计划；同一专注不会重新启动；今日在 880×620 窗口能直接看到个人行动；全局搜索无需先猜分类；时间轴缩放不改变实际安排。
