# Pare Android 0.7：更清楚、更有质感的页面

用户要求优化布局、颜色与字体；沿用已经确认的专业、紧凑、突出Pare特点的方向。此次只调整呈现与信息展开，不新增业务模式，不修改任务、运行、同步或AI授权逻辑。

## 设计决定

考虑过继续纯白平铺、加重整屏品牌色、以及柔和底色加重点分层。选择第三种：保留列表扫描效率，用背景与表面区分层次，深绿承担主动作，暖金强调今日重点和选中状态。避免重新回到大标题、大统计卡占满首屏的布局。

| 元素 | 决定 |
|---|---|
| 底色 | 柔和浅中性色，内容表面接近白色；深色主题使用低饱和深绿灰 |
| 文字 | 正文16sp/24sp，辅助13sp/20sp，分组16sp/24sp，页标题20–24sp；专注数字单独32–36sp |
| 对比 | 正文与辅助文字、按钮文字均检查至少4.5:1，颜色不作为唯一状态提示 |
| 圆角 | 控件8dp、输入12dp、重点内容16dp、弹层24dp；不把所有按钮做成大胶囊 |
| 间距 | 4/8/12/16/24dp节奏；相同内容对齐，同组收紧、不同组留白 |
| 交互 | 点击区域至少48dp，大字体/长标题自然增高，保存与错误仍清楚可达 |

## 各页面

- 主页：标题与导航稳定；添加任务是主操作，AI为次级入口。任务用连续轻表面承载，今日重点暖金标识，保留六任务首屏密度。
- 想法：阶段、当前问题、关联行动、探索时间线各有层级，强调从长期探索到具体行动。
- 录入与计划：减少同等粗细的文字堆叠，按信息目的分组，选择控件在宽度允许时紧凑并排，大字体退回纵向。
- 专注：时间为视觉中心，当前状态与下一步次之，运行范围说明降低权重。
- 提醒：时间为主，重复规则紧凑选择；真实权限状态可见，系统设置按需展开。
- AI：建议首先可见，连接、参考与原始输入维持按需展开，原有授权与采纳保护不变。
- 账号与回看：状态、内容与操作分组；个人和外部记录分开，不堆装饰统计。
