# Windows 完整日常流程

用户在逐项缺口审查后明确要求“都做一下吧”。本轮继续现有 Compose Desktop / Kotlin 共享领域模型、已批准图标和深绿暖金外观，补齐已列出的缺口；开发不等待重复范围确认。Windows 发布仍与实现、CI 验收分开。

## 设计决定

- 主导航增加资料库和回顾；任务常用动作直接可用，低频管理收进详情或右键菜单。今日保留紧凑总览，并可切换可操作时间轴。
- 四象限支持跨象限移动及插入排序，今日支持排序；时间块支持拖入、移动、调长短和跨日安排。落点预览、取消和过期基线保护不可少；底层复用既有 actions，不绕过同步冲突约束。
- 资料库统一搜索任务、收件、想法和目标，可筛选已完成、归档、截止与本机回收站。删除明确确认，回收站保留可恢复内容，归档和恢复不偷偷恢复今天的承诺。
- 任务详情补截止日期、总预计/实际分钟校正。今日行与随手记提供专注/暂停、下一步完成；卡点引导可保存更小行动并启动5分钟。
- 回顾展示已有完成和投入记录、8周趋势与估时校准；等待与个人投入分开，缺记录不猜测。
- AI仍由明确点击发起。本地轻提示支持冷却/暂缓；提供背景、偏好确认/修改/忘记、建议反馈和本机原始历史查看/删除。只有预览中授权的参考进入请求。
- 备份导入先校验和预览，保留恢复前快照；不得导入凭据/模型密钥或覆盖新修改。自动备份损坏恢复有真实入口。
- Windows提供可选登录自启、可操作通知、退出后的系统提醒、可校验的更新检查/安装流程；不自动启用监控、安装或更改用户启动项。系统级动作只能用户在设置中开启。
- 注意力提醒在本机判断空闲/频繁切换，默认关闭且可暂缓；不采集截图或上传应用/浏览历史。
- 桌面小组件采用 Step 自有紧凑浮窗，包含今日重点、下一步、记下和专注控制，可固定在桌面；不冒充 Windows Widgets 系统面板集成。
- 其他设备运行状态复用已有 presence 协议，只显示有时效的状态参考；远程暂停/结束/接管不在此前列明的“查看”要求内，仍在运行设备操作。

## 验收边界

隔离虚构资料库完成行为、持久化、失败保护、键盘与鼠标工作流检查，Windows CI运行完整测试和安装器自测。真实个人电脑上的输入法、DPI切换、系统通知交互、自启、更新保留数据仍需实机证据；缺少实机时记录为待验收，不标为已验证。所有密钥与真实数据不进入Git或公开图。
