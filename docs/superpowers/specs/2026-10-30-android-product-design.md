# Pare Android：从展示卡片到日常工作界面

用户要求研究成熟应用，并由我们决定布局、尺寸、颜色和交互规则。本规范替代0.3的装饰性深绿卡片方案。研究是官方截图和交互说明的桌面调研，未声称登录或亲自完整使用竞品；Things官网部分素材为历史产品图，不能代表最新系统样式。

产品约束：遵循[产品原则](../../product-principles.md)。列表优先是改善扫描与操作的手段，Pare的价值仍是想法孵化、四象限取舍、有限容量的今日规划、最小下一步、个人/并行推进与有历史上下文的AI。用户明确要求不照搬竞品的功能组合；借鉴基础体验后，必须让页面服务于这些自己的核心流程。

## 证据与决定

| 参考 | 观察到的原则 | Pare 的决定 |
|---|---|---|
| [Things官方功能页](https://culturedcode.com/things/features/)及Today图片 | 普通任务是可扫描的行；可选详情在展开后出现 | 删除常驻任务工具栏，普通任务采用紧凑行，重点只增加必要强调 |
| [Todoist Quick Add](https://www.todoist.com/help/todoist/features/use-task-quick-add-in-todoist-va4Lhpzz) | 先输入标题，可选描述和属性按需出现 | 新建使用自动聚焦的快速输入面板，填写标题即可保存 |
| [Todoist Android任务详情](https://www.todoist.com/help/todoist/features/use-the-task-view-to-manage-tasks-in-todoist-eDeRDO0C) | 列表与详情分工，元数据和次级操作在详情中 | 已有任务使用完整详情；列表只保留完成、编辑入口和更多菜单 |
| [Todoist导航](https://www.todoist.com/help/todoist/features/customize-the-todoist-navigation-bar-L4qpkI0xj) | 导航项代表目的地 | 今天、整理、想法为三个目的地；添加是独立且有明确标签的动作 |

## 视觉规格

| 元素 | 规格与理由 |
|---|---|
| 页面顶栏 | 56dp，标题24sp；账号48dp点击区。去掉PARE品牌行、常驻宣言和大头像 |
| 页面上下文 | 日期/计划简报一行，13sp；正常同步不占内容行，只在账号图标上显示小状态；异常才显示提示 |
| 横向网格 | 页面16dp；内部8/12/16dp步进；组间24dp，普通行间0dp |
| 任务行 | 普通内容基准64–80dp；16sp/24sp标题，13sp/18sp辅助信息最多一行；长标题和大字体自然增高 |
| 重点任务 | 小星标与淡金色背景/3dp标记，目标不超过104dp；不重复金边、金标题、金标签和取消按钮 |
| 行操作 | 左侧完成48dp；中间标题进入详情；右侧更多48dp。移入/移出今天、设/取消重点放进明确菜单 |
| 导航 | 80dp以内加系统安全区；3个目的地，不再嵌套大胶囊。单独的添加按钮明确写添加任务/随手记/记录想法 |
| 圆角 | 普通列表无独立大卡片；小控件8dp，必要分组容器12dp，输入面板上角24dp |
| 字体 | 标题24/32、任务16/24、正文14/22、辅助13/18、标签12/16，全部sp，尊重系统缩放 |
| 明亮主题 | 背景/内容以白色和浅中性色为主；正文#1D2522，次级#626C66，分隔#E7E9EC，主动作绿#246B4A |
| 深色主题 | 中性深色#151918/#1C2220；正文#E6ECE8，次级#A5B2AA，主动作浅绿#99D2B3 |
| 金色 | 仅用于今日重点：浅色#936510/淡金底#FFF6DE，深色#E4C279/底#2E2B20 |
| 语义色 | 象限颜色只作辅助标记并保留文字；错误使用红色；不把整个屏幕染成品牌色。默认跟随系统主题 |

## 页面和交互

**今天：** 紧凑标题/日期，简单完成与估时摘要；重点任务和其它待办列表；已完成折叠。没有任务时一个简短引导和明确添加入口，不展示空统计卡。

**整理：** 有待整理内容时优先展示；为空只显示一行入口/说明。象限标题负责分组，组内不重复整段象限名称。整理收件箱条目时明确选择象限、可选加入今天，再原子转换为任务；不再无提示地归入第二象限。

**想法：** 标题、阶段、最多一行摘要和更新时间的紧凑列表；不使用营销式“花园”标题。点击进入完整内容编辑，长期项目的信息保留。

**新建：** 标题自动聚焦、键盘打开；标题即可保存。可选下一步、备注、估时、象限通过“更多信息”展开，展开状态与草稿一起保存。保存按钮必须在键盘上方可见。

**详情：** 已有任务与新建区分；完整编辑区域有清楚的返回/保存操作，滚动承载长内容，错误固定可见。保持失败不关、旋转不丢、远端变更不被旧草稿覆盖的规则。

**更多菜单：** 所有操作有文字和48dp热区；不要求用户学习隐藏手势。导航和添加的对象明确，提交/完成有即时状态反馈。暂不增加未经验证的滑动删除、自动保存或复杂动画。

## 验收

- 在约360×800dp、标准字体、6条常规两行任务的测试数据中，首屏至少完整显示6条任务；首条任务起点≤180dp。
- 1.6倍字体不强求同样密度，但不得截断主要操作或重叠热区，内容可滚动。
- 点击添加即可输入，标题即可保存；填写可选字段需要主动展开。
- 任务更多菜单、分类选择、编辑保护、完成与持久化均通过正式模拟器测试。
- 浅色和深色实际渲染、长标题、空列表、账号和键盘状态均生成截图检查。
- 不改同步协议、认证权限、Mac应用或真实用户数据；QA包与正式模拟器应用数据隔离。
