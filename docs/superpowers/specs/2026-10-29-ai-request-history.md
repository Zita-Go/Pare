# 本地 AI 请求历史

用户已确认补齐本地请求记录：实际输入、模型原始输出、状态，可查看/复制/删除，排除密钥，后续发送仍单独控制。

选择独立的本地历史目录，不把原始记录塞入任务Store或自动模型上下文。相比仅保存摘要，它能够核对原始结果；相比把原文直接并入任务备份和历史检索，它避免默认扩大后续发送范围。本轮不更改任务schema，不补造旧请求。

- 同时覆盖智能助手、旧AI入口与设置里的示例连接测试。
- 从真正发送的URLRequest取得body，包括system指令、用户数据、model与schema；不保存请求头。响应保留脱敏原始文本，成功/HTTP错误/格式失败/取消均有明确状态。正文最多128KB，超出标记截断。
- 记录时间、模型、服务地址、HTTP状态、耗时；当前请求通过独立记录ID关联，预览与历史分开命名。
- 本机Application Support中独立目录，目录700、文件600，原子写入；最多100条/20MiB，单条有界。删除不会在旧备份中自动复活。崩溃遗留的进行中记录标为中断。
- 密钥仅在内存用于脱敏；不保存Authorization、Cookie等header，内容中的实际密钥、Bearer及典型凭据字段也脱敏。不写入源码、仓库或任务备份。
- 默认折叠入口：助手“本次请求详情”；设置AI页“请求历史”。详情显示模型回复和实际输入/原始响应，复制内容不包含密钥；删除有明确确认。没有原始响应的旧记录无法回补。
- 保留当前授权与AI建议校验、取消语义；原始历史只供用户查阅，不自动附带给模型。磁盘错误明确提示，不能假报保存成功。

版本2.12.0 build39。验证包括持久化重启/删除/截断/脱敏/失败取消，真实网络测试仅本地假服务，不发送用户真实记录。
