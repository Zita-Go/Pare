# Mac 2.13.0 / Android 0.1.0 同步开发预览

2026-10-30。本地开发产物，尚未发布 GitHub Release，也未替换现用 Mac App。

## 开始体验

1. 在现用 Mac Pare 的「设置 → 数据」先导出备份，退出 Pare 后再安装测试包。新版本使用数据格式 7；旧版本不能直接读取升级后的资料库，回退须使用备份。
2. Android 8.0 及以上可安装 `Pare-Android-0.1.0-debug.apk`。这是开发签名测试包。
3. Mac 打开「设置 → 同步」；Android 打开右上角「账号」（登录后显示「同步」）。注册一个 Pare 同步账号，确认邮件后，两端使用同一邮箱登录。此账号与 Supabase 管理控制台账号独立。
4. 首次连接先查看合并预览，再确认开启同步。未开启时仍可离线记录。有版本差异时比较本机/云端内容后选择；同一组关联修改会一起应用。

默认 Supabase 邮件服务只适合开发测试；开放给其他用户前应配置正式邮件服务、配额与运营策略。此预览不承诺所有手机型号的后台实时同步。

## 范围

Mac 新增可选同步、按日期保存的计划、持久化同步队列、冲突处理及会话存储。任务、备注、想法、探索记录、目标、计划和明确的规划偏好可以同步。设备通知/快捷键、正在运行的计时、模型连接密钥和 AI 原始历史留在本机。

Android 首版包含今天、整理、想法三个页面，支持随手记、任务编辑/完成、今日选择和重点、账号、离线保存、手动/前台同步。移动端专注计时、提醒、AI和后台同步尚未实现。

## 验收

- Swift 完整测试 322 项通过，含 30 项资料库同步测试与 14 项 HTTP 测试。
- Android 29 项测试通过；构建成功，lint 0 错误、10 项非阻断建议，APK 签名有效。
- 虚构账号的真实 HTTP 验收：Swift/Kotlin 载荷互通，重试幂等、完成、删除、冲突选择、账号隔离、登录刷新和退出。
- 临时云端验收账号与同步数据已删除并查询确认无残留，未上传正式任务或 AI 历史。
- Mac 隔离预览检查了登录/注册切换与同步范围说明。
- Android API36 ARM64 模拟器启动和安装通过；CUA 无法绑定独立 QEMU 窗口，因此未完成手机界面的点击/截图验收。实际手机安装、邮箱注册与网络稳定性仍需验收。

## 构建

Mac：`bash build_app.sh`。Android：`./android/build.sh testDebugUnitTest assembleDebug lintDebug`。

云端项目配置放在 Git 忽略的 `backend/supabase/project.local.json`，只打包公开项目地址与 publishable 客户端键。服务端管理员密钥不得放入客户端。跨语言验收程序为 `Scripts/SyncCloudAcceptance.swift`，仅接受显式指定的临时测试账号和资料库。
