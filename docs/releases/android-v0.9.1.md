# Android 0.9.1：专注时长单行显示

专注预设改为 **5、15、30、60 分钟**。四个按钮等宽放在同一行，有明确间距，选中时保持金色高亮；下面仍可输入自定义时长。默认从5分钟开始。

原来的自动换行布局只设置了横向间距，第四个按钮换行后紧贴上一行。本次用固定单行布局解决，未改动等待结果的检查提醒或已在运行的计时。

## 验证

- Debug构建、Lint通过（0错误）。
- 真实弹窗验证320dp普通字号、280dp与1.6倍系统字号（实测按钮行分别为272dp和232dp）：按钮同一行、等宽、不重叠，文字实际边界完整。
- 点击预设只更新选择；开始后发送60分钟专注指令。手填7分钟也能正确开始，并取消预设高亮。
- 两项新增弹窗测试与两项既有执行流程通过；本次未重复完整测试套件。
- 截图来自独立QA包的虚构任务，未使用真实资料。
