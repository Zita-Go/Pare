Step for Windows 0.3.0 让日常规划与推进更直接。

- 今天可以直接添加任务到正在查看的日期；有今日重点时，突出“开始 5 分钟”，并保留其他时长选择。
- 四象限明确显示规划日期，任务行直接加入或移出该日；选入之后再设置重点，减少日期误解。
- 点击时间概览或时间轴中的事项，直接进入“安排与提醒”。跨午夜时间块使用原始安排日期。
- 同步状态区分本机保存、拉取、待确认、等待、失败、暂停和已同步；不会把“已开启”当作同步成功。账号失效提示不会被一次本机编辑覆盖。
- 想法中的关联行动可直接打开，新建后可就地继续写下一步；返回时保留想法草稿和页签，子任务的日期与未保存安排也保持不变。
- 窄窗口优先显示单列行动，时间概览按需展开；宽窗口保留受限宽度的时间侧栏。外观、快捷键、托盘与桌面小窗统一从“设置 → 外观与快捷键”进入。

保存输入并退出旧版后，可覆盖安装。已有资料、账号与同步进度继续保留，无需清空数据。提供 Windows 10/11 x64 的 EXE、MSI 和免安装 ZIP；校验值见 SHA256SUMS.txt。安装包尚无商业代码签名。
