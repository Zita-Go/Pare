Step for Windows 0.2.2 修复首次同步卡在“预览尚未就绪”、确认按钮不可点击的问题。

- 首次登录和主动拉取可以继续读取较长的云端历史，不再因为读满 100 页就中断。
- 设置 → 账号与同步新增“继续拉取云端内容”，从已保存的进度继续，无需退出账号。
- 重开应用后仍可继续准备首次合并；拉取完成后才允许确认开启自动同步。
- 确认开启前不会上传本机内容；已有本机修改、冲突和账号绑定继续保留。请求仍有超时、取消和逐页校验保护。

**从 0.2.1 更新：**保存输入并关闭 Step，运行新版安装包覆盖安装，保留现有资料目录。重新打开后进入“设置 → 账号与同步”，点“继续拉取云端内容”；完成后点击“确认合并并开启同步”。之后自动同步，无需每次手动开启。
