# Step for Windows 0.4.1

修复完成任务立即从象限消失的问题，并让象限间拖动更清楚。

- 当天完成的任务保留在原象限底部，显示勾选和删除线，可直接取消完成；切换页面或取消选中后仍然可见。
- 按规划时区跨日后，旧完成项从象限收起，记录继续保留在「搜索与记录 → 已完成」。切换正在查看的计划日期不会提前隐藏当天完成项。
- 拖动把手更大，有悬停说明与移动光标；拖动时显示任务来源，目标象限高亮并提示「松开移入」。支持 Esc 取消和撤销。
- 很矮的窗口可滚动查看四个象限，任务操作和底部添加框保持可达。

下载 `Step-0.4.1.exe` 覆盖安装。之前已经完成的任务没有被删除，更新后今天完成的任务会重新显示；更早的完成记录可在「搜索与记录」找到。
