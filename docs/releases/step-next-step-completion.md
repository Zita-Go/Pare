# Step：逐步完成任务（2026-11-19）

本地开发版本：Mac2.16.0/build45，Android0.15.0/code21。

## 怎样使用

1. 给任务写下一个具体的下一步并保存。
2. 做完后点“完成这一步”。记录内容、完成时间和当时的完成标准，并清空当前下一步。
3. 可以接着填写新的下一步，也可以先留空、下次继续。整个任务仍保持未完成。
4. 在“已完成的步骤”中回看进展；误点后可撤销，已有新步骤时不会覆盖它。

Mac入口：任务详情、卡点/拆小一步，以及今日计划和随手记的“下一步”按钮。安卓入口：任务的专注/推进面板和卡点支持表单。历史默认折叠，保持主界面简洁。下一步与完成标准有未保存修改时，先保存后再完成；其他草稿保留。

## 数据与保护

步骤历史作为任务的可选completedSteps数组保存。旧数据可读取，新旧客户端同步的未知字段保留机制继续使用，不需要后端迁移。记录进入现有任务同步；本轮没有新增AI调用，也没有扩大AI上下文上传范围。

完成一步不改变任务的完成状态、今日安排、提醒、估时、专注或并行运行。保存失败不会显示成功；过期请求和同名后续步骤使用最近完成记录ID校验，重复请求不会消费新步骤。撤销仅恢复最后一步，且不覆盖新动作、标准或未保存草稿。
