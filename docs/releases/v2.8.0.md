# Pare 2.8.0 — 可信与顺手

本次围绕日常使用和数据可靠性，继续使用本地 schema v4。

## 更顺手

- 今日重点与正在专注的状态统一；个人行动优先呈现，并行任务可折叠。
- 待整理侧栏可主动收起；今日计划默认获得更宽的空间。
- 搜索入口常驻，支持 ⌘F，默认跨任务、想法和历史查找。
- 时间轴提供缩放和回到现在，便于浏览更长时段。
- 任务行不因悬停增加第二行；估时、提醒与实际用时使用按需弹窗。

## 更可信

- 明确的未来提醒语句直接创建带提醒的任务，无需先分类。
- 保存问题在主界面可见，支持重试；导入失败不替换现有内容。
- 保护来自未来数据版本的文件，禁止自动用旧备份覆盖。
- 同一数据目录的第二实例转向已有实例；正常退出结束个人专注，中断恢复明确提示补记。

## 验收与分发

本机候选构建为 2.8.0 build 33；完整验收结果见 `Tests/RELEASE_ACCEPTANCE.md`。
