# Step for Windows 0.4.0

这一版让 Windows 的整理与随手记更接近 Mac：打开就能分清轻重，常用操作就在任务旁边。

- **熟悉的四个工作区**：四象限、今日计划、搜索与记录、想法与项目。待整理栏可以收起，顶部和任务行减少空白。
- **在象限里直接添加**：写下任务并回车；草稿在切换页面后仍保留，保存失败可继续修改和重试。
- **随手记随时继续**：回车保存后保持面板打开，支持 Ctrl+Enter、Esc 收起、完整今日任务、运行任务、详情、完成和整理入口。
- **就近开始并行**：任务旁可以开始、暂停、继续和结束并行记录，也可设置或取消检查时间。多项并行可以与一项个人专注同时进行，等待不算个人投入。
- **键盘整理**：点击键盘图标后，用上下键选择、1–4 归类、空格完成或恢复、Esc 清除选择；Ctrl+F 进入搜索。
- **想法安排回看**：可以设置、清除回看时间；已有背景、探索记录和关联行动保留。

下载 `Step-0.4.0.exe` 安装，或选择 MSI、便携包。覆盖安装前一版本会保留本机资料。账号同步仍需在设置中完成首次确认。

两端仍有差异：Windows 随手记使用 Esc、快捷键或关闭按钮收起，尚不支持点击其他应用自动收起。Mac 的中文时间识别、每日规划/收尾/每周回顾定时提醒，以及部分系统触发计划尚未完整移植。支持情况见[功能对照](https://github.com/Zita-Go/Pare/blob/main/docs/qa/windows-mac-parity.md)。
