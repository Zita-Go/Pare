# Pare 2.11.0 — 更清晰、安静的工作界面

保留深绿与暖金的风格，整理整个应用的视觉层级和操作反馈。数据格式继续使用 schema v6。

- **更容易找重点：** 导航使用中性选中底色，暖金主要用于关键操作；降低卡片描边、阴影与背景干扰。
- **更协调的排版：** 统一标题、正文和辅助文字层级，调整中英文混排、行距与间距；控件、卡片和浮层分别使用 8、12、18 点圆角。
- **更明确的操作感：** 按钮提供悬停、按下和禁用反馈；输入框显示焦点边框；任务详情保留 36×32 点点击区域，悬停不改变布局。
- **更容易理解结果：** 保存与完成用绿色，错误用红色，说明用蓝色，并配有图标和文字；AI 请求失败时清除过期的成功提示。
- **更一致的页面：** 四象限、今日计划、随手记、想法详情、AI 助手和设置共用基础控件；保留已有的渐进展开、撤销和草稿保护。
- **照顾不同显示需求：** 保留文字缩放，系统减少动态效果时关闭本轮过渡动画；减少透明度和提高对比度时使用更清晰的背景与边界。

这是 2.11.0 build37 本地候选，尚未公开发布。视觉修改不改变 AI 服务地址、密钥、授权范围或任务操作规则；外部模型服务故障与真实建议质量不属于这轮视觉验收结论。
