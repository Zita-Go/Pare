# Pare 2.5.0 — 界面与 AI 规划预发布版

这是预发布版本，欢迎试用和反馈，不代表稳定版全部场景已经验收。

## 本次更新

- 统一深色界面、文字对比度、按钮和卡片层级；主窗口增加清晰的「设置」入口及 `⌘,`。
- 任务标题和时长状态分行，改善窄窗口阅读；任务详情固定保存/取消，日期提醒按需展开。
- 设置按「通用、提醒、AI、数据」分类，切换时保留未保存的连接草稿。
- AI 可协助整理随手记、拆出下一步和安排本次时间；结果优先展示行动与完成标准，完整分析可展开。
- 加入自选本地历史参考、长期目标、规划偏好和反馈；参考范围可明确记住或取消。
- AI 返回内容严格校验。超预算等失败显示具体原因与只读参考，不自动写入任务、不自动重试；采纳仍由用户决定。
- 测试通知根据系统提交结果显示成功或失败，不再在被拒绝时误报已发送。

## 下载与安装

- 安装包：`Pare-2.5.0-macos-arm64.zip`，仅面向 Apple Silicon（M 系列）。
- 系统要求：macOS 13 及以上。本次原生验收在 Apple Silicon Mac 上完成，未提供 Intel 安装包。
- 核对 `SHA256SUMS.txt` 后解压，将 `Pare.app` 拖到「应用程序」。更新前先导出备份并退出旧版。
- 本包只有本地 ad-hoc 签名，尚无 Developer ID 签名或 Apple 公证；macOS 可能拦截打开。也可从此标签的源码使用 `./build_app.sh` 构建。

## 隐私与 AI 配置

AI 默认关闭，安装包不含用户任务、模型服务配置或 API Key。使用者在 App 内配置自己的服务；Key 存入 macOS 钥匙串，只有明确选中的参考内容会发送到所配置的服务。不开启 AI 时，核心记事与规划不依赖模型服务。

当前临时签名在版本更新后可能引发钥匙串重新授权。请核对请求的 App 和条目，不向所有应用开放钥匙串访问，也不要把系统密码填进 AI 对话。

## 验证与已知限制

- 128 项自动测试通过。
- 已做隔离原生 UI 验收、模拟 API 错误恢复/采纳验收、真实 API 虚构示例联调；普通测试通知的到达已由用户确认。
- **仍未完成**浏览器页面增强检测到通知动作的真实完整链路、各类通知动作，以及实际机器休眠/唤醒的端到端验收。
- 跨日、夏令时和停止计时后的数据逻辑有自动测试，但这些不等于真实休眠测试。长期目标与反馈能力不代表无人值守、自主执行的通用 Agent。
- 系统权限、专注模式和屏幕共享设置会影响通知展示。注意力提醒是可忽略的启发式提示，不能判断用户是否真正有动力或正在工作。
