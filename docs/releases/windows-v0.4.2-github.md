# Step for Windows 0.4.2

让任务操作更统一，拖动方式更接近 Mac。

- 星星、太阳和「…」排在同一行，星标不再单独占一行。所有未完成任务都有重点入口；尚未加入当前计划日的任务，点星星会一次完成加入与设为重点。取消重点会保留当天任务。
- 去掉任务前方的拖动把手，按住任务文字或空白区域即可拖动。半透明任务预览跟随鼠标，保留原来的抓取位置。
- 目标象限使用原有颜色的细边框，不再整卡染成亮黄色。支持 Esc 取消、拖到有效区域外松手取消，以及移动后的撤销。
- 完成、星标、太阳、详情及专注等按钮仍独立响应点击；从按钮按下后移开不会误拖任务。

0.4.1 的当天完成保留、跨日收起和短窗口滚动继续保留。下载 `Step-0.4.2.exe` 覆盖安装即可。
