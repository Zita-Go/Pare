Step 的 Windows 10/11 x64 预览版，适用于 Intel、AMD 电脑。

推荐下载 **Step-0.2.0.exe** 安装；也提供 MSI 和免安装 ZIP。压缩包中的 `SHA256SUMS.txt` 可用于核对文件。

这版包括四象限拖拽、今日清单与可操作时间轴、最小下一步和专注、想法与目标、资料库及回收站、回顾、同账号同步、AI建议与本机历史、备份恢复、桌面小窗和可选Windows提醒功能。

默认随手记快捷键是 **Ctrl+Shift+Space**。登录自启、退出后提醒、注意力检测和浏览器增强在“设置 → Windows”中单独开启；AI请求、建议采纳、更新下载和安装均由用户明确操作。

这是**预览版**，尚无商业代码签名。现有构建已通过自动化测试、安装启动、0.1.0升级保留数据、原生注册及清理验证。补充输入、缩放与锁屏检查的实际结果将在发布前补入本页；不能把离屏渲染当作物理多显示器或真实输入法候选窗验收。

任务内容可与同账号的Mac/Android同步。运行状态仅供参考，不远程接管其他设备计时；旧版客户端升级前不会显示Windows设备。模型密钥、AI原始历史和反馈仅加密保存在本机。
