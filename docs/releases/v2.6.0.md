# Pare 2.6.0 — 并行任务状态

此开发版本新增“进行中”，用于跟踪交给其它机器、外部 AI 或他人处理的任务。Pare 不连接或管理这些执行者，只记录任务何时开始、何时检查以及何时暂停或完成。

## 核心规则

- 个人「专注」仍然只允许一个任务；多个「进行中」任务可以并存。
- 进行经过时间与个人实际投入分开保存，不进入专注统计或估时校准。
- 今日计划增加「正在进行」区域，并在菜单栏显示 `↻N` 数量。
- 随手记里的每个未完成任务可直接启动或暂停「专注」与「并行」，无需先打开详情或菜单。
- 可设置 15／30／60／120 分钟后的检查提醒；通知支持完成、暂停和延后检查。
- 状态会随本地备份保存，重启和跨日继续显示；完成或删除任务时自动结束对应状态。
- 同一任务不能同时专注与并行进行，避免重复计时。

数据格式升级到 schema v3。旧数据可以直接读取；使用 2.6.0 保存后，不建议再用 2.5.x 打开同一数据文件。
