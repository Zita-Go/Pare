# Pare 2.5.1 — 通知图标修复预发布版

这是 2.5.0 的预发布补丁，包含同一套界面与 AI 规划改版，并改善 macOS 通知中心识别应用图标的稳定性。

## 本次修复

- 同时声明 `CFBundleIconFile` 与 `CFBundleIconFiles`，明确引用打包后的 `AppIcon.icns`。
- 菜单栏模式启动时显式载入应用图标，让运行实例和 LaunchServices 使用同一资源。
- 文档明确要求把 Pare 拖到「应用程序」后运行，避免从 `dist`、下载临时目录或被反复覆盖的路径长期启动。

## 下载与安装

- 下载 `Pare-2.5.1-macos-arm64.zip` 与 `SHA256SUMS.txt`，核对 SHA-256。
- 仅支持 Apple Silicon（M 系列），要求 macOS 13 及以上。
- 退出旧版，解压后将 `Pare.app` 拖入「应用程序」，再从该位置启动。
- 如果通知中心仍显示旧缓存，请重启 Pare 后重新发送测试提醒；反馈时请附通知横幅截图。

## 安全、隐私与限制

安装包不含用户任务、模型服务地址或 API Key。AI 默认关闭；使用者自行配置的密钥保存在 macOS 钥匙串中。

本包仍为本地 ad-hoc 签名，尚未经过 Developer ID 签名和 Apple 公证。版本更新后 macOS 可能再次询问钥匙串访问；请核对请求来自 Pare，不要向所有应用开放密钥。

128 项自动测试通过。浏览器增强检测到通知动作、其它通知动作及实际休眠/唤醒仍未完成全链路验收；本版本继续标记为 Pre-release。
