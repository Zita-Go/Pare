# Step 开发预发布：Mac 2.16.0 / Android 0.15.0

从 Pare 2.7.1 之后的本地开发版本汇总。源码与安装包对应本次GitHub预发布，适合试用与反馈，不是应用商店正式发行。

## 主要变化

- **从 Pare 更名 Step**：白底、绿色折面S和金色目标球，表达一步一步推进。保留既有安装、账号与资料库身份。
- **完成一步，再继续下一步**：独立标记步骤完成、保留内容/时间/标准、查看历史和安全撤销；整个任务不自动完成，提醒和计时保持原样。
- **想法慢慢长成项目**：记录探索、发现与决定，再关联具体行动；四象限与今日规划继续承担取舍和安排。
- **Mac与Android可选同步**：本地离线修改、自动同步、首次合并预览与冲突处理。AI密钥和原始请求历史不随任务同步。
- **有前情的可选AI协助**：用户选择任务与参考范围，预览建议后再采纳；本地请求历史可检查。没有预置模型API密钥。
- **安卓规划与执行**：紧凑今日清单、可拖动时间轴、优先级整理、专注/等待记录、提醒和桌面组件。
- **Mac编辑快捷键**：补齐系统全选、复制、剪切、粘贴、撤销及重做。

## 下载与安装

- Mac：`Step-2.16.0-macos-arm64.zip`，Apple Silicon，macOS13+。先备份、正常退出旧版，将Step.app放入应用程序后启动。只有Apple Silicon安装包；Intel用户需从源码自行构建并验证。
- Android：`Step-0.15.0-android-debug.apk`，Android8.0+。测试签名包；只能直接覆盖兼容签名的旧安装，升级前保留资料备份。
- 校验文件：`Step-SHA256SUMS.txt`。

从2.7.1升级包含资料库格式变化；旧版不能直接读取新资料库。回退前应使用升级前导出的备份，而不是直接用旧程序打开新文件。

## 验证范围与限制

上传前在当前源码上复验Swift359项测试和Android384项单元测试。步骤流程的Android隔离模拟器原生QA2项通过；另有此前已有启动流程验收。Mac构建及本地签名验证通过，Command-A曾在实际窗口确认；本轮步骤UI尚未完成Mac桌面端到端验收。Android未完成物理手机验收，后台提醒和同步仍受系统省电策略影响。

Mac包使用本地ad-hoc签名，未做Developer ID签名或Apple公证；Android为debug签名。本次明确标记为预发布。启用同步后，Mac首次读取保存的凭据可能等待系统钥匙串授权，需要用户在系统窗口完成；此前遇到过此处阻塞启动，不能将未授权状态视为正常启动完成。

随包仅包含同步服务所需的公开客户端配置，不包含管理员凭据、模型API密钥、个人任务或AI原始记录。托管同步服务仍是开发体验环境，邮件配额和服务容量不作生产承诺。
