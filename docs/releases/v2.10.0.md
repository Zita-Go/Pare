# Pare 2.10.0 — 记得前情，走出下一步

本地候选 build35。三个情境入口共用受控的 AI 协议：想法详情的「接着想一想」、今日规划的「帮我安排」、卡点面板的「帮我开始」。

- 上下文来自获准的当前对象、关联探索记录、行动、历史反馈与确认偏好。可展开查看发送内容和引用。
- 仅点击生成才请求模型；失败不自动重试。继续调整会保留本轮明确要求，失败或取消仍可查看原有效建议。
- 每项变更可选择，整批成功保存才显示已采纳；支持幂等与冲突安全撤销，不能跨日恢复昨天的安排。
- 偏好需要用户单独确认，支持设置中编辑/忘记；反馈不自动变成稳定偏好。
- 今日投入与整项任务估时分开，时间块不重复计数，人工检查与后台并行运行分开。
- 本地轻提示支持回看、行动结果与明确卡点，带去重、稍后与本周抑制。专注期间隐藏，暂放想法只按明确回看日期提示。
- AI 写入的探索记录可见标记来源，原始想法继续保留。

## 验证

234 项测试通过，包括本地 HTTP 成功/错误/重定向/取消/超时、有界上下文、迁移、原子写入、撤销、偏好与提示策略。三场景完成本地假模型 UI 验收；真实模型质量评测尚未完成，未发送用户内容到外部服务。
