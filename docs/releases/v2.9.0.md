# Pare 2.9.0 — 想法与项目

把初期的宏观想法留作持续发展的空间，再从中产生具体行动。

- 新的「想法与项目」入口：萌芽、探索、推进、暂放和归档。
- 每个想法保留当前描述、下一步探索问题、按时间记录的发现与决定。
- 一个想法可以派生或关联多个任务；完成任务不会移除想法，归档任务仍可追溯。
- 任务详情可打开来源想法，搜索支持探索记录。
- 回看使用温和提示，不把想法标记为逾期；归档想法退出回看提醒。
- 原长期目标仍从想法页访问；规划偏好位于设置的 AI 分类。

## 数据兼容

写入 schema v5，兼容读取旧版本数据；原有想法默认处于萌芽阶段，标题、备注和回看时间保留。
2.8.0 遇到 v5 数据会进入只读保护。需要回退应用时，应同时恢复升级前的数据备份，不要让更旧且不具备版本保护的应用写入这份新数据。

本地候选构建为 2.9.0 build 34。未公开发布，仍需 Developer ID 签名、公证及独立环境验收。
