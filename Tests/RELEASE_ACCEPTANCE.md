# 2.5.0 预发布验收记录

更新：2026-09-06。按最新发布授权，将 2.5.0 作为预发布版交付；下列未完成项目明确保留，不宣称已通过稳定版全量验收。

## 已验证

- 128 项自动测试通过，包括跨日、夏令时、跨午夜计时、已停止计时重载、浏览器切换策略边界、主窗口设置入口，以及新阅读层级和分类草稿保留契约测试。
- 本地 2.4.2（build 21）已构建、验签并启动。主窗口新增可见「设置」和 `⌘,`；隔离 App 已验证点击打开、关闭后重开及重复进入设置。窗口关闭后自动化失去目标时通过演示菜单重新定位；线程采样未见主线程卡死。
- 隔离 UI 验收：任务详情保存/取消、AI 参考范围记忆/撤销记忆、随手记收起再展开。
- 本机模拟 API 验收：超预算拒绝及只读预览、手动重试、未选择时禁用采纳、采纳写入动作/完成标准并保留原估时。2 次请求，无额外自动重试。
- 修复并实测普通测试通知被系统拒绝时的错误反馈。之前的 UI 不等待提交结果便显示“已发送”；普通和漂移测试入口现在均通过提交回调反馈，进行中禁止重复点击。系统接受不等于横幅已经展示。
- 用户已确认正式 Pare 的普通测试提醒可以收到；此项不代表通知动作按钮或浏览器自动触发链路通过。
- 2.5.0（build 22）界面改版已构建并验签。隔离实测涵盖 880pt 主窗口标题/状态分行、四类设置导航与未保存 AI 草稿保持、长分析展开全文、详情固定操作及日期展开、目标/历史/回顾和随手记收起再展开。
- 2.5.0 已在用户允许后重启运行。新包位于 `dist/Pare.app`。

## 稳定版仍待完成的验收

- 通知点击动作。普通提醒到达已由用户确认；独立验收 App 被系统拒绝通知，不能把其“提交失败”分支通过当作动作按钮或其它通知类别通过。
- 浏览器增强：真实浏览器页面切换，经辅助功能事件、策略判断到通知与用户动作的完整链路。自动策略测试不能替代此项。
- 实际电脑休眠/唤醒时的计时停止与恢复提醒。已通过的测试只验证可控时间下的数据逻辑，没有修改系统时钟或让电脑实际休眠。
- 独立干净环境安装与跨版本升级的进一步验证。当前包为 Apple Silicon、本地 ad-hoc 签名；未做 Developer ID 公证。

## 隔离测试入口

`bash Scripts/screenshot-demo.sh --verify-shortcuts --verify-integrations`

打开测试 App 的「演示 → 验证快捷键设置」。使用独立虚构数据和设置；检测默认关闭。系统权限应由用户明确允许，不通过测试脚本修改授权数据库。正式用户数据与密钥不用于 fixture，也不进入仓库。

本次使用 GitHub Pre-release 标记，并在版本说明中列明这些限制；不将自动数据测试或模拟 API 验收冒充真实系统端到端验收。
